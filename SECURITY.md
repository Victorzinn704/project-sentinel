# Politica de Seguranca

## Escopo

O Project Sentinel lida com gateway local, politicas de permissao, auditoria e chaves locais. Vulnerabilidades em autenticacao, autorizacao, armazenamento SQLite, logs, configuracao ou fluxo OpenAI-compatible devem ser tratadas como sensiveis.

## Como reportar

Nao abra issue publica com token, payload exploravel, chave local ou detalhe que permita abuso. Use um contato privado indicado no perfil do GitHub ou um aviso privado de seguranca quando o recurso estiver disponivel.

Inclua:

- versao, commit e sistema operacional;
- configuracao minima para reproduzir;
- impacto esperado;
- evidencia redigida, sem credenciais reais.

## Prioridade de resposta

Credencial exposta, bypass de politica, acesso sem autorizacao e vazamento de logs sensiveis devem ser corrigidos antes de qualquer discussao publica detalhada.
